# logos/ — โลโก้บริษัทสำหรับการ์ด Live Snapshot

- **ที่มา:** [nvstly/icons](https://github.com/nvstly/icons) → `ticker_icons/` (เวอร์ชันสำหรับธีมมืด พื้นหลังโปร่งใส)
- **รูปแบบ:** PNG 96×96 โปร่งใส จัดกึ่งกลาง · การ์ดแสดงที่ 34px
- **ครอบคลุม:** 451 จาก 503 ตัวใน S&P 500 (ณ `constituents.csv` ที่อยู่ในโฟลเดอร์นี้ของ repo)
- **ตัวที่ไม่มีโลโก้:** การ์ดใน `index.html` สลับไปแสดงอักษรย่อเองผ่าน `onerror` → `.snap-logo.no-logo` ไม่ต้องแก้อะไร
- **อัปเดต:** `python tools/fetch_logos.py` (เติมเฉพาะตัวที่ขาด) หรือ `--force` เพื่อโหลดทับทั้งหมด

## สิทธิ์การใช้งาน
รีโปต้นทาง **ไม่มีไฟล์ LICENSE** และตัวโลโก้เป็นเครื่องหมายการค้าของแต่ละบริษัท
ไม่ใช่ทรัพย์สินของรีโปต้นทางที่จะอนุญาตต่อได้ การใช้ในหน้านี้เป็นการใช้เพื่อ
**ระบุตัวบริษัทที่อ้างถึง** เท่านั้น ไม่ได้สื่อว่าบริษัทเหล่านั้นรับรอง สนับสนุน
หรือมีความเกี่ยวข้องใด ๆ กับ JP Trust Learning
